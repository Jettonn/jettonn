### About Me

- Full stack engineer from **Kosovo**, frontend-heavy by trade
- I build production web apps **end to end**: TypeScript on both sides, Vue, React, Next.js and Nuxt on the front, Node, C# and .NET on the back
- Shipped dashboards, delivery systems, and shared component libraries across startups, agencies, and enterprises
- Creator of [**originui-vue**](https://github.com/Jettonn/originui-vue), a Vue 3 component library with **200+ stars**
- Currently building two full stack side projects: [**Prezento**](https://prezento.jettonn.dev/) and [**ShowWhen**](https://showwhen.jettonn.dev/)
- Open source contributor to projects like [Reka UI](https://github.com/unovue/reka-ui) and [Tiptap](https://github.com/ueberdosis/tiptap)
- Pursuing a **Master's in Computer Science** at UBT
